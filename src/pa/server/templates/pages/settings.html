Default waiting capacity: 100. Provisioning and provider startup consume execution slots; durable waiting records do not. A value of 0 disables waiting when execution is full.

Default: 4 slots. This preserves the historical ceiling and is intentionally conservative because PA cannot infer host resources or provider account limits. Legacy capacity:N tags remain readable only when a typed setting is absent.
