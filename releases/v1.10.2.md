# v1.10.2 — 1.10.2

**Release track:** release  
**Date:** 2026-11-18

## Summary

Patch release centered on durable card evidence and steadier Work/session behavior: completion records and attachable materials stay discoverable, expanded Work views hold through refreshes, and Codex/ACP session continuity improves. Operators running cards with attachments, completion evidence, or Codex sessions should update.

## Highlights

- Durable completion records with a discoverable Results collection on cards
- Versioned specification links and durable card material workflows, including attachment management in details
- Expanded Work results and Done cards preserved across overlapping refreshes; incomplete task outcomes no longer satisfy whole-task Done
- Codex sessions default to correct launch permissions, restore unprompted threads reliably, and can carry additional ACP directories
- Standing intent and selected-work authorization survive recovery, continuation, and independent card outcomes

## Added

- Versioned, immutable completion records with title/summary, Markdown sections, durable references, and a card Results viewer
- Versioned specification links, larger typed discussion details, material history, and shared attachment quotas
- Durable card attachment management in details (view, download, upload, resource links, edit, replace, remove)
- Additional ACP directories on session creation, MCP start, new-session UI, preferences, and instance defaults
- Inbox disposition for capture/research turns that should not auto-start implementation

## Changed

- Codex background sessions default to agent-full-access; explicit selections and restored sessions keep their modes
- Standing authority, preferences, and current user intent carry through admission, continuation, recovery, and reconciliation
- Selected-work receipts and frozen bounded selections persist through retries and successor attempts
- Work expansion retains requested result counts and scroll anchors across refreshes; incomplete/waiting outcomes leave task completion pending
- Binding inspection reports bounded rejection categories and preserves exact lease API timestamps in read hashes

## Fixed

- Codex restoration for durably confirmed unprompted sessions
- Card session start completing to the exact created conversation instead of stalling on “Starting…” or selecting an older worker
- Expanded Done cards and attention-filter pages surviving Work refreshes and live completion updates
- Continuation caps reporting a concrete resource-limit error without inventing a new approval gate
