# v1.1.2 — 1.1.2

**Release track:** release
**Date:** 2026-08-23

## Summary

v1.1.2 completes the interrupted v1.1.1 fleet rollout with startup recovery for missing sync-history objects, reachability-aware canonical card-history repair, and compatibility with current MiniMax structured summaries.

## Highlights

- Recover missing sync-history objects during startup without entering a crash loop
- Re-anchor canonical card histories when their recorded heads are no longer reachable
- Accept current MiniMax structured summary responses
- Retain bounded sync protocol v3 and managed updater restart and provenance repair from v1.1.1

## Changed

- Card-history recovery now considers object reachability before preserving a canonical head
- Summary parsing accepts structured MiniMax content blocks in addition to plain text

## Fixed

- Restore startup when a sync ref names a missing history object, allowing affected instances to recover through supported synchronization
- Prevent unreachable canonical card-history heads from blocking fleet reconciliation
- Prevent valid MiniMax summaries from failing solely because the provider returns structured content
