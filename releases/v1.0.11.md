# v1.0.11 — 1.0.11

**Release track:** release  
**Date:** 2026-08-16

## Summary

This release makes the Home page feel faster by rendering the shell immediately and loading the command grid asynchronously, matching Work’s placeholder pattern. Anyone using the web UI Home view should notice snappier first paint.

## Highlights

- Home first paint no longer waits on the workshop snapshot or a full-realm presentation count
- Home renders chrome right away with Work-style `Loading …` placeholders
- Command grid fills from `/partials/home/sections` on load and `homeRefresh`
- Retry/focus restore still works after the grid swap; Home reports `X-PA-Home-Bytes` like Work

## Added

- Async Home section placeholders filled via `/partials/home/sections`
- `X-PA-Home-Bytes` response header on the Home shell (parity with Work)

## Changed

- Home loads as a fast shell first, then hydrates the command grid asynchronously instead of blocking on workshop snapshot and realm presentation count
