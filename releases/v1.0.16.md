# v1.0.16 — 1.0.16

**Release track:** release  
**Date:** 2026-08-17

## Summary

Patch release that keeps Cursor, Codex, and OpenInterpreter visible in the New session provider picker (and Fleet remote start) instead of falling back to Instance default after a stale HTMX snapshot or form reset.

## Highlights

- New session provider list fills from the shell catalog as soon as you open the dialog
- Registered ACP runtimes stay in shell JSON so options survive `form.reset()` and SPA navigation
- Fleet remote start uses the same catalog and no longer hides runtimes whose live probe reported unavailable

## Changed

- Provider options for New session and Fleet remote start come from the shell catalog (including after `/providers/catalog`), not only from a cached select that may look empty

## Fixed

- Stale HTMX Agent snapshots plus `form.reset()` no longer wipe JS-added provider options back to Instance default

## Upgrade

```bash
pa update
# or fresh install:
curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```
