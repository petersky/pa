# v1.0.1 — 1.0.1

**Release track:** release  
**Date:** 2026-08-06

## Summary

This release hardens PA’s governed Goal, dispatch, and fleet-control paths for safer retries and identity binding, and makes Workshop, Projects, telemetry, and capacity reporting more truthful and operable. Operators and teams running Goals, Fleet, Workshop, or Projects should update.

## Highlights

- Canonical Goals authorization, audit, evidence, and fleet-control path (#238)
- Transactional incremental WAL dispatch storage replaces the dispatch ledger (#244)
- Workshop made bounded, truthful, and responsive (#248)
- Projects disclosures, health metrics, and session/PR history pagination (#249)
- Safer card-summary retries, limbic trust/replay, and capacity accounting (#246, #237, #250)

## Added

- Scoped assigned-service MCP bridge for Goal governance
- Durable Goal governance foundations and assigned-service governance completion
- Paginated project session and PR history

## Changed

- Enforce one canonical Goals authorization, audit, evidence, and fleet-control path (#238)
- Bound Goal mutation responses; derive mutation identities on the server; bind retries to exact payloads and canonical operations
- Bind governed materialization envelopes, evidence ingestion, provider resume/wait generations, and fleet dispatch provenance
- Replace dispatch ledger with transactional incremental WAL storage (#244)
- Make card summary retries operationally safe (#246)
- Prefer live project sessions over quiesced history; make Projects disclosures and health metrics operable (#249)
- Harden limbic trust and replay accounting (#237)
- Preserve telemetry gaps and unit-correct report axes (#247)
- Make Workshop bounded and responsive with truthful focus and projection safeguards (#248)
- Make deep event history iterative and restore card creation (#236)
- Clarify Fleet capacity backlog display and normalize authoritative capacity consumers

## Fixed

- Close governed execution identity crash cuts and recover exact identities
- Make goal dispatch admission and control authority crash-/partition-safe
- Fix auxiliary dispatch store isolation; redact provider launch data and unlaunched providers from conflict/portfolio reads
- Fix queued prompt capacity accounting (#250); prefer semantic session state and current capacity consumers
- Fix card summary review blockers
- Fix Workshop projection correctness, empty dispatch indexes, and operational evidence preservation
- Fix telemetry rollup parity, report bounds, and accessible inspected values
- Revert unsafe PR-watch lease caching, workload-profile normalization, and service log rotation before deployment (#245, #243, #242)
