# v0.2.39 — 0.2.39

**Release track:** release  
**Date:** 2026-08-03

## Summary

This release hardens fleet dispatch and MCP bootstrap: PA now runs on MCP SDK 2, puts dispatch in a shared modal across surfaces, and fixes placement timeouts and target-aware provider/model selection so fleet operators get more reliable admissions.

## Highlights

- PA MCP bootstrap and contracts migrate to MCP SDK 2 (`mcp>=2.0.0,<3`)
- Card dispatch moves into a shared accessible modal with entry points on Home, Work, Workshop, and card detail
- Fleet MCP handshake gets its own timeout budget and clearer failure diagnostics
- Dispatch provider/model inputs become normalized, target-aware selectors
- Packaged MCP smoke coverage lands in CI (initialize → tools/list → shutdown)

## Added

- Shared Dispatch modal for fleet targeting, configuration, validation, progress, retry, and errors
- Consistent Dispatch entry points from card detail, Home, Work, and Workshop
- Lockfile-independent packaged MCP wheel install and stdio smoke in CI

## Changed

- MCP server, module contracts, browser image results, and related tests now use the MCP 2 `MCPServer` API
- Doctor/`pa update` recovery guidance classifies stale 1.x and future-major MCP SDKs
- Agent tab stays focused on local session state; dispatch controls live in the shared modal
- Forced MCP bootstrap refreshes coalesce, keep bounded successful evidence, and distinguish timeout, unhealthy, dependency, owner-channel, and transient failures
- Omitted provider selection resolves on the chosen target instead of inheriting the authority host default
- Legacy `None` model values normalize; provider field errors return structured responses

## Fixed

- Fleet overview no longer wraps the MCP stdio handshake in the generic short fleet deadline
- Codex-only (and other target-limited) workers no longer inherit Cursor from the authority host during dispatch
- `httpx.ReadTimeout` diagnostics no longer crash when a response attribute is missing
- Card-item actions hide for dispatched cards and update immediately after admission or race rejection

## Upgrade

```bash
pa update
# or fresh install:
curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```
