# v1.9.0 — 1.9.0

**Release track:** release  
**Date:** 2026-11-10

## Summary

The chat composer is more expressive: `@` mentions attach files, images, cards, conversations, and users; `!` runs a shell command; `$` opens the skill menu; and conversations open in a dialog from any page. This release also hardens fixed-session recovery and wire metadata, and makes `release.sh --ship` finish the channels PR.

## Highlights

- Composer `@` mentions for files, images, cards, conversations, and users (resolved on the server)
- `!command` runs a shell command from chat; `$` opens the skill menu
- Shared trigger parser with slash-command fixes
- Open conversations in a chat dialog from any page
- Stronger fixed-session recovery and bounded wire outcome metadata

## Added

- Composer `@` mentions for files, images, cards, conversations, and users
- Composer `!command` to run a shell command from chat
- Shared composer trigger parser and `$` skill menu
- Chat dialog to open conversations from any page
- Bounded fixed-session wire outcome metadata with signed snapshot cursors
- Fail-closed exact-session recovery audit

## Changed

- `@` mentions resolve on the server; retained chat images are pruned
- Closed-session recovery is sealed before provider admission
- Native branch identity and concurrent recovery aliases are guarded
- `release.sh --ship` also merges the channels PR

## Fixed

- Slash-command handling in the composer
- Flaky tests: wait for dialog teardown; match whole numbers instead of CSRF digits
- Dismissed restart receipts reconciled from exact completion evidence
