## Summary

This release hardens agent sessions and fleet reliability: managed GitHub token auth for agents, a reconnect fix after network changes, clearer ready/status UI for new chats, and safer card and dispatch reconciliation.

## Highlights

- Managed `GH_TOKEN` auth for agents
- Agent session reconnect no longer flips incorrectly after network changes
- New agent chats show a ready state before the first prompt
- Card summary provider connection test
- Bounded fleet discovery refreshes and stale closed-session dispatch repair
