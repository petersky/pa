# v1.7.0 — 1.7.0

**Release track:** release  
**Date:** 2026-11-08

## Summary

Cards and the Work board now show progress as a short stage strip instead of blocks of status text, the board is grouped by state by default, and notification cards no longer offer "Retry delivery" while a response is actually being delivered. Merged cards whose worker has finished are now handed to the independent verifier instead of sitting stuck.

## Highlights

- **Stage strip:** every card shows `Work → checkpoints → Done` with who owns the current step, a liveness pulse for running agents, and a tally for parallel child cards
- **Work board grouped by state** (Needs you / In motion / Not started / Done); "By lane" is an opt-in toggle that keeps drag-between-lanes
- **One-line board cards** and a reordered, quieter card dialog
- Notification cards show "Delivering your response…" while delivery is in flight instead of a Retry button
- **Behavior change:** stalled merged cards that only the local operator can accept are verified automatically (see Upgrade)

## Added

- Stage strip on cards, the Work board and Home
- `completion_auto_verify_stalled_seconds` setting (default 24h; `0` disables)

## Changed

- `/work` opens grouped by state; the lane board is available with `By lane`
- Board cards drop redundant "Open card" buttons; Done cards are plain titles
- Card dialog folds away summary tools and shows a visible Lane label
- Work filters collapse to a single row
- A parent card with a running child is shown as In motion

## Fixed

- No "Retry delivery" button or delivery-state text while a response is being delivered
- A Done card whose stale-version reconciliation already converged is no longer flagged as needing attention
- Sign-in prompt says "Sign in to complete manually" unless acceptance is actually the next step

## Upgrade

```bash
pa update
# or fresh install:
curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```

**Automatic verification.** A card with a declared verification policy is switched to the independent verifier once, when it is merged, its only acceptance principal is `user:local`, and every dispatch on it has been finished for 24 hours. That runs a verifier agent without asking. To opt out, set `completion_auto_verify_stalled_seconds` to `0` before upgrading.
