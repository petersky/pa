# v1.0.10 — 1.0.10

**Release track:** release  
**Date:** 2026-08-16

## Summary

This patch release fixes macOS LaunchAgent startup over SSH and after `pa update`. If you run PA as a LaunchAgent on a headless Mac or update remotely, you should install this build.

## Highlights

- LaunchAgent plist allows Aqua and Background session types so `pa start` works over SSH
- `pa update` restarts via the newly installed `pa` binary instead of the pre-update process
- Clears the remaining launchd bootstrap 125 failure left after the v1.0.9 `user/` domain fallback

## Fixed

- LaunchAgent bootstrap failing with error 125 on headless/SSH sessions because agents defaulted to Aqua-only
- Post-update restart still running old service logic from the pre-update process

## Upgrade

```bash
pa update
# or fresh install:
curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```
