# v0.2.31 — 0.2.31

**Release track:** release  
**Date:** 2026-07-29

## Summary

This release improves Workshop and projects UX, hardens agent session lifecycle and fleet dispatch behavior, and adds clearer ACP and Codex sandbox observability. Operators and anyone running multi-agent or projects workflows should update.

## Highlights

- Workshop live floor view for real-time activity
- Redesigned projects workspace navigation with Projects and Repos sidebars
- Safer idle agent session recovery and automatic session closure
- Authoritative ACP session observability and Codex sandbox admission health tracking
- Fleet improvements: group participation placement and scoped dispatch with degraded peers

## Added

- Workshop live floor view
- Projects and Repos sidebar navigation with searchable, scrollable lists and center editing
- Private owner socket and explicit web listeners
- Authoritative ACP session observability
- Codex sandbox admission health tracking
- Card dispositions rendered as chat status

## Changed

- Enforce fleet group participation placement
- Keep completed dispatches terminal and evaluate turn outcomes
- Defer idle agent session recovery: recover only unfinished sessions at startup, defer passive retained sessions, and lazily coalesce runtime admission for follow-up work
- Enforce automatic agent session closure
- Allow scoped dispatch with degraded peers

## Fixed

- Reconcile squash-merged workspace cleanup

## Upgrade

```bash
pa update
# or fresh install:
curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```
