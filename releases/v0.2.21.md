# v0.2.21 — 0.2.21

**Release track:** release  
**Date:** 2026-07-25

## Summary

Patch release that stops ACP from creating new Cursor sessions while PA is shutting down. If you hit orphaned sessions or cascading `session/new` / `runtime is not live` errors after `pa stop`, upgrade.

## Highlights

- Block ACP `session/new` during shutdown so stop cannot orphan Cursor sessions
- Abort in-flight connect and durable resume once shutdown is signaled
- Fence and cancel background ACP startup before module teardown

## Fixed

- Stop ACP `session/new` during shutdown resume races (background resume could still call Cursor `session/new` while Uvicorn was shutting down, leaving sessions missing from the next boot’s `session/list`)
- Abort in-flight `AgentConnection.connect` (including the missing-`session/list` → `session/new` fallback) when process shutdown is signaled
- Stop durable resume loops on shutdown without treating them as recovery failures

## Upgrade

```bash
pa update
# or fresh install:
curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```
