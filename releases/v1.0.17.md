# v1.0.17 — 1.0.17

**Release track:** release  
**Date:** 2026-08-17

## Summary

Patch release for card summaries and responsiveness tests: summaries can reuse a stored Codex provider API key when `PA_CARD_SUMMARY_API_KEY` is unset, and mixed-load event-loop stall checks no longer treat GitHub xdist jitter as a failure.

## Highlights

- Card summaries fall back to a configured Codex API key instead of failing when no dedicated summary key is set
- Mixed-load event-loop stall detection no longer flags normal GitHub Actions xdist noise as a stall

## Changed

- Card summary auth resolves a dedicated `PA_CARD_SUMMARY_API_KEY` first, then reuses provider-scoped credentials from `integrations/codex.json` when that env var is missing
- Setup guidance for unconfigured summaries points at configuring Codex with `pa agent-provider configure` as an alternative to a dedicated summary key

## Fixed

- Cards no longer show as summary-failed solely because `PA_CARD_SUMMARY_API_KEY` was unset while a Codex provider key was already stored
- Responsiveness tests stop treating GitHub xdist runner jitter as a mixed-load event-loop stall
