# v1.1.3 — 1.1.3

**Release track:** release
**Date:** 2026-08-23

## Summary

v1.1.3 is a focused recovery patch for fleets whose realms contain more than 20,000 reachable sync-history objects. It allows a healthy peer to restore the small number of actually missing objects without rejecting the realm because its valid local history is large.

## Highlights

- Repair a missing event in a realm with more than 20,000 reachable commits
- Bound authenticated peer requests and fetched objects instead of total local history
- Preserve durable refs while rebuilding the DAG index and projection
- Retry cleanly after peer availability returns and transition health/readiness back to normal

## Changed

- Startup recovery now begins with the diagnosed missing or corrupt object and performs incremental local validation after each bounded peer fetch
- Recovery diagnostics report privacy-safe request, fetch, validation, head-change, and limit counters

## Fixed

- Prevent POST /api/sync/recovery from returning unrecoverable solely because a valid reachable realm exceeds 20,000 objects
- Reject corrupt or unavailable peer responses without moving refs or publishing a partial projection
- Preserve the diagnosed recovery target across retries so a temporarily unavailable peer can be retried safely
