# v1.0.0 — 1.0.0

**Release track:** release  
**Date:** 2026-08-04

## Summary

PA 1.0.0 is the first major release for operators and fleet owners who need durable goal orchestration, multichannel intake, and more reliable long-running agent sessions across Workshop, Work, and Fleet.

## Highlights

- Durable and supervised goal orchestration with advanced autonomy and governance
- Canonical multichannel intake for attributable work across channels
- Limbic appraisal and tiered memory for richer agent context
- Resumable card agent sessions with automatic enrichment and async semantic summaries
- Dispatch wait, macOS keep-awake, and iterative sync/replay for more reliable deep histories

## Added

- Canonical multichannel intake
- Durable goal orchestration (Phase 1) and supervised goal orchestration
- Advanced goal autonomy and governance
- Limbic appraisal and tiered memory
- Resumable card agent sessions
- Automatic card enrichment
- Async semantic card summary generation
- Dispatch wait and macOS keep-awake support
- Safe card project changes
- PA favicon assets and route
- Live fleet activity in Workshop

## Changed

- Collect deep sync histories and replay deep event histories iteratively
- Coalesce repeated derived progress updates
- Propagate canonical fleet instance renames
- Automatically authorize bounded continuation prompts
- Wait for transient dispatch sync lag
- Bound Work page history and live resources
- Coordinate SPA navigation cancellation
- Keep Sessions available during agent startup
- Extend workspace reconciliation and session observability MCP timeouts
- Stabilize durable dispatch admission
- Run summary migration only on the fleet owner
- Avoid re-verifying retained backups during pruning
- Speed up Settings page loading
- Improve agent session list readability

## Fixed

- Workshop compact view
- Transient ACP session recovery
- MCP probe teardown false timeouts
- Stale peers resurrecting card lanes
- Reports chart rendering
- Fleet topology edge layering and selection highlighting
- Workspace reconciliation evidence
- Attributable fleet legacy repair
