# v0.2.23 — 0.2.23

**Release track:** release  
**Date:** 2026-07-25

## Summary

This release hardens multi-instance fleet workflows: card attachments travel with dispatch, completion reconciliation retries survive restarts, the Work board stays in sync after peer lane changes, and operators get clearer upgrade progress plus control-plane compatibility diagnostics.

## Highlights

- Card attachments are portable across fleet sync and remote dispatch
- Completion reconciliation retries are durable with bounded backoff and operator repair
- Work board refreshes live after peer lane sync
- Fleet upgrades show durable modal progress per instance
- New fleet control-plane compatibility diagnostics endpoint

## Added

- Realm-synced card attachment manifests with content-addressed storage, authenticated create/remove APIs, and verified fleet transfer for remote dispatch
- `GET /api/fleet/control-plane/status` compatibility diagnostics (legacy static routing vs consensus authority; no behavior change)
- Durable fleet upgrade modal with phase-derived progress and per-instance job restore
- Authenticated idempotent operator endpoint to re-arm stranded completion reconciliation

## Changed

- Completion reconciliation persists structured retry state and uses bounded exponential backoff with jitter
- Remote dispatch negotiates attachment manifests and blocks session start until required artifacts verify

## Fixed

- Work board no longer stays stale after peer lane sync advances a realm
- Fleet upgrade UI no longer shows stale progress when switching instances or reopening the modal

## Upgrade

pa update
