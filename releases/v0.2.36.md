# v0.2.36 — 0.2.36

**Release track:** release  
**Date:** 2026-08-03

## Summary

This release strengthens fleet operations and CLI consistency: durable dispatch queuing under load, policy-driven collaboration modes, fleet interactions/notifications, and clearer diagnostics and logs. Operators running multi-instance fleets and anyone living in the PA CLI day to day should update.

## Highlights

- Durably queue dispatches when execution capacity is full, with fair exact-once promotion
- Policy-driven collaboration modes and slash commands
- Durable fleet interactions and notifications
- Consistent semantic formatting and unified CLI terminal presentation
- Actionable doctor diagnostics and complete timestamped service logs

## Added

- Queue dispatches beyond execution capacity with bounded queue config, readiness recovery, and operational surfaces (#187)
- Policy-driven collaboration modes and slash commands (#186)
- Durable fleet interactions and notifications (#185)
- Consistent semantic formatting across the PA CLI (#184)
- Per-instance auxiliary MCP servers
- Complete timestamped service logs with filtering, safe follow, and redacted NDJSON (#180)

## Changed

- Unify CLI terminal presentation
- Protect and rotate fleet sync credentials
- Make doctor diagnostics actionable

## Fixed

- Monica systemd environment and owner-channel startup (#179)
