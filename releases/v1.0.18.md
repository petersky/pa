# v1.0.18 — 1.0.18

**Release track:** release  
**Date:** 2026-08-18

## Summary

This is a maintenance release for anyone running PA with external ACP agents—especially Codex and OpenInterpreter with MiniMax models. It fixes session startup failures and improves chat feedback when an agent is thinking but not yet streaming output.

## Highlights

- Fix Codex sessions failing to start when Codex expects named permission profiles instead of a legacy top-level `permissions.network` grant
- Fix OpenInterpreter/MiniMax sessions failing admission because PA advertised effort levels the model does not support
- Show a waiting state in agent chat when the provider streams nothing during quiet thinking turns
- Resolve `npx` on the service PATH so Codex can spawn correctly from LaunchAgents and other non-interactive contexts

## Changed

- OpenInterpreter provider options no longer invent high/medium/low effort levels unless the live model advertises an effort control; MiniMax-M2.x models use fixed thinking and stay at the default
- Agent chat surfaces a waiting indicator when an OpenInterpreter turn produces no transcript events yet

## Fixed

- Codex session startup with current Codex permission-profile semantics: PA now grants the owner unix-socket on a real named profile (`pa-owner`) selected via `default_permissions`, including migration away from legacy top-level network grants
- OpenInterpreter new-session configuration for MiniMax-M2.x: skip no-op effort applies that caused admission to fail
- Codex CLI discovery under macOS LaunchAgents by resolving `npx` through the service PATH
