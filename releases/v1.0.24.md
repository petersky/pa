# v1.0.24 — 1.0.24

**Release track:** release  
**Date:** 2026-08-22

## Summary

This release is for operators running PA sessions, fleet placement, and card summaries. Interactive chats stay open after associated cards complete, retired card links keep their history, card summaries can use write-only MiniMax or Claude keys, and fleet/ACP behavior is more honest and reliable.

## Highlights

- Add write-only MiniMax and Claude card-summary providers (openai, anthropic, or minimax in Settings)
- Keep standalone sessions open after associated cards complete
- Preserve retired association history across relinking
- Keep fleet enrichment inside the advertised capability catalog and attach worktrees to resumed sessions
- Fix ACP combined model/effort selectors and theme flash on startup

## Added

- Write-only MiniMax and Claude card-summary providers. Operators can choose openai, anthropic, or minimax in Settings and store per-provider keys that are never returned after save. Claude uses the native Messages API; MiniMax stays OpenAI-compatible; Codex fallback remains OpenAI-only.

## Changed

- Standalone sessions retire the card association when the card completes instead of closing the chat; dispatch-owned sessions still close with their work.
- Relinking a session to a card archives the previous retired association interval instead of overwriting it.
- Fleet enrichment stays inside the advertised capability catalog, automatic placement can select a local compatibility-derived instance, MCP exposes `resume_session_id` and placement rejections, and a leased worktree attaches to the resumed live session instead of spawning a sibling.
- New Chat distinguishes loading from empty models, and the Sessions row shows the applied model, mode, and config.
- Cursor and OpenInterpreter skip the extra pre-session PA MCP stdio probe Codex already avoided.

## Fixed

- ACP combined `model[effort]` selectors no longer fail when the agent advertises model and reasoning together; theme and appearance apply before the stylesheet loads so startup no longer flashes the wrong variant.
- Session owner lookup is latency-bounded so the composer cannot stay stuck locating a session; a known owner falls back to the live snapshot when the fleet route lookup is slow or unavailable.
