# v1.10.0 — 1.10.0

**Release track:** release  
**Date:** 2026-11-11

## Summary

Loops is a first-class surface for schedules and reminders, Workshop and autonomy keep cards and goals moving without silent stalls, and chat queue, recovery, and delivery are more reliable. Anyone running agents through completion, managing notifications, or using Workshop should take this update.

## Highlights

- Loops page with session reminder alarm, then a redesign around readable schedules and guided editing
- Autonomy fixes across chat queue, recovery, dispatch, goals, notifications, and Workshop floor view
- Workshop no longer starves browser connections or fails completion reconciliation on an undeclared setting
- Chat UX: outside-click menu dismiss, simpler prompt controls, title carryover and paused-reply fixes, MCP readiness from Codex completion deltas
- Faster session history, scheduler, and transcript paths; verified source builds with historical benchmark bulk removed

## Added

- Loops page for one-time, repeating, cron, event, and webhook notification schedules
- Session chat alarm for pending reminders with accessible per-widget dialog
- Workshop floor view with stations mapped to live agent states
- Stall notifications (failed prompt, lost connection, blocked recovery, failed dispatch, closed PR, hung turn)
- Opt-in Telegram push for notifications (replies bound to the notification they answer)
- One-time repair commands: `pa sessions repair-recovery`, `pa dispatch repair-stuck`, `pa card drop-active`
- Selective verified source wheel builds with a 64 MiB source budget and attestation

## Changed

- Loops leads with searchable notification cards, readable schedules, status filters, and a three-part editor
- Chat queue: Stop holds the rest until Resume; FIFO survives restart; duplicate bubbles removed
- Recovery blocks on deterministic errors and reclaims dead-session worktree leases after rescue
- Completion/post-turn follow-through wired; card policy defaults loosened mid-run; several autonomy defaults updated (previous values remain available)
- Composer: Queue label on active turns, accessible stop control, capped textarea; pop-up menus dismiss outside / Escape
- Scheduler, session history, transcript, knowledge, and PR-watch paths batched or kept off writer slots
- Historical oversized benchmark dumps retired; compact summaries retained

## Fixed

- Workshop connection starvation when probing remote bays; undeclared `reconciliation_session_unavailable_seconds`
- Chat title carryover across sessions and paused reply rendering in short history windows
- MCP “PA tools starting” readiness stuck after successful Codex completion deltas
- Cross-instance dispatch completion, stale-running / lost-remote detection, and completion delivery that never gives up
- Goal supervisor defaults: Pause, VERIFYING, Activate, and approval requests
- Offline / closed legacy owner collection and cleaned-workspace fixture remnants
- Reserved-session and immutable workspace proof reconciliation before retirement repair

## Upgrade

```bash
pa update
# or fresh install:
curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```
