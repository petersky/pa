# v1.3.0 — 1.3.0

**Release track:** release  
**Date:** 2026-09-06

## Summary

This release focuses on managed agent sessions: persistent chats, clearer runtime state, actionable notifications, and capability-aware execution admission. Operators and users who run agents through PA should upgrade for more reliable session recovery and safer preference-driven execution.

## Highlights

- Persistent chats with managed agent activity tracking
- Capability-aware execution preferences, policy checks, and audited admission
- Actionable agent notifications
- Fresh session sidebar runtime state
- Safer managed session recovery and sync catalog backfill

## Added

- Persistent chats and managed agent activity
- Capability-aware execution preferences, policy, and audited admission
- Actionable agent notifications

## Changed

- Session sidebar keeps runtime state fresh
- Main lifecycle handling uses a shared blocked-prompt contract
- Managed browser coverage kept local; workspace selection fixtures no longer depend on host providers

## Fixed

- Managed session recovery edge cases
- Stale sync object catalogs are detected and backfilled safely

## Upgrade

```bash
pa update
# or fresh install:
curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```
