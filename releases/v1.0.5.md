# v1.0.5 — 1.0.5

**Release track:** release  
**Date:** 2026-08-15

## Summary

This release improves standalone agent sessions and the session list UI, closes completed card-enrichment sessions so they no longer clutter active chat, and hardens CI so the full test suite runs reliably.

## Highlights

- Compact, information-dense agent session list with live state, context, usage, and related cards
- Durable many-to-many session/card associations and a “Capture in card…” flow for standalone sessions
- Completed Enrich jobs close durably instead of lingering as active sessions
- Codex/Cortex ACP defaults to full-access when no mode is selected
- Full-suite CI stabilized and made host-independent

## Added

- Durable many-to-many agent-session/card associations (REST and MCP)
- Standalone-session “Capture in card…” flow to link an existing card or create a new one
- Bounded canonical PA project, repository, and card catalog context for unbound agents
- Compact session-list rows with provider monogram, title, live state, card/project and repository context, instance, elapsed time, model/mode, turns, tokens, related cards, and supervised PR status
- Details disclosure for secondary session actions (config, activity, memory promotion, close/forget)

## Changed

- Default Codex/Cortex ACP dispatch to `agent-full-access` when no mode is explicitly selected
- Session-list instance names may use roughly 32 characters before truncation
- Associated cards shown throughout session history and card/project projections
- GitHub Actions runs the complete pytest suite instead of only a boot smoke test
- Locked development dependencies for `pytest` and `pytest-asyncio`

## Fixed

- Completed one-shot card-enrichment sessions now close durably; orphaned `card-enrichment:*` sessions are repaired by the lifecycle sweeper
- Nested session-list controls no longer accidentally switch the active session
- Workshop snapshot treats unavailable fleet activity payloads as empty
- Managed Chromium startup hardened with a wall-clock deadline and attempt cap
- Full-suite tests no longer depend on host-specific ACP paths, sockets, color settings, or shared-runner disk latency
