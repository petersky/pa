# v0.2.20 — 0.2.20

**Release track:** release  
**Date:** 2026-07-25

## Summary

This patch release hardens ACP lifecycle control: one-shot `--no-acp-resume` now actually skips recovery for a single boot, and shutdown paths fence admissions, force-stop cleanly with `--no-acp-quiesce`, and escalate stuck ACP children. Operators who start, restart, or stop PA with those flags should upgrade.

## Highlights

- Make `--no-acp-resume` a consume-once boot marker that suppresses durable ACP recovery and default session attachment for that boot only (#91)
- Fence ACP admissions before shutdown and disconnect runtimes concurrently
- Add a fast force-stop path for `--no-acp-quiesce` without waiting on quiesce snapshots
- Bound normal transport shutdown and kill stuck ACP child processes

## Changed

- `--no-acp-resume` / restart with that flag now persist a one-boot marker and leave durable sessions nonterminal for later explicit reopen or a normal boot
- Document one-boot, non-destructive no-resume semantics in ACP docs

## Fixed

- Fix ACP shutdown races with background startup and blocking teardown (#91)
- Fix one-shot resume flags so skip-resume actually suppresses durable recovery and default ACP attachment (#91)
