# v1.0.8 — 1.0.8

**Release track:** release  
**Date:** 2026-08-16

## Summary

A reliability and performance release: cleaner shutdown under Ctrl+C, faster startup off-loop work, and lighter CI on release PRs. Operators who restart `pa serve` often or cut release branches should upgrade.

## Highlights

- Close SSE streams as soon as shutdown begins so Ctrl+C no longer surfaces as an ASGI crash
- Treat Uvicorn’s forced `CancelledError` during shutdown as expected instead of an error
- Cut startup worker-pool saturation from repeated object-store walks and deep dispatch copies
- Skip pytest shards on `release/v*` PRs while keeping the smoke check for publish gates

## Changed

- Projection WAL, sync object-store listing (one pass), and dispatch scans now do less redundant off-loop work at startup
- Release PR CI (`release/v*`) skips pytest shards; the smoke job still runs

## Fixed

- Shutdown cancellation noise from open SSE streams and Uvicorn task cancellation
- Startup slow-op floods caused by repeated object-store walks and deep dispatch copies

## Upgrade

```bash
pa update
# or fresh install:
curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```
