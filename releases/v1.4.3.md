# v1.4.3 — 1.4.3

**Release track:** release  
**Date:** 2026-09-06

## Summary

v1.4.3 improves session recovery and startup ownership, adds audited repository scope settings for GitHub supervision, and enriches missing card fields through summary automation.

## Highlights

- Fence concurrent session startup and recovery to prevent duplicate runtime owners
- Restore durable continuation queues after recovery and restart handoffs
- Manage GitHub supervision repository scope through explicit, audited settings
- Enrich missing card fields through the configured summary provider

## Added

- GitHub supervision scope settings with validated repository selection, audit evidence, and a shared API/UI path

## Fixed

- Concurrent recovery now returns a retryable conflict while session admission is in progress
- Startup and connection fencing protect runtime publication and stale connection callbacks
- Recovery restores pending continuations and distinguishes durable recovery state in session presentation and observability
- Card creation and summary automation can enrich missing fields while preserving supplied content
