# v1.0.7 — 1.0.7

**Release track:** release  
**Date:** 2026-08-16

## Summary

This release tightens release-tooling reliability and speeds up CI. Maintainers who cut releases and contributors who wait on GitHub checks get the most value; day-to-day PA runtime behavior is unchanged from v1.0.6.

## Highlights

- Release runner can resume a prepared `release/vX.Y.Z` branch after a failed PR create instead of bumping again and aborting
- Transient GitHub 504s during release PR create are retried, with recovery if the PR was created anyway
- CI pytest runs are sharded across two workers and parallelized with xdist; Chrome dump-dom tests are dropped from CI

## Changed

- GitHub Actions pytest is split into shards and run with xdist for faster full-suite checks
- Chrome dump-dom layout tests are excluded from CI (they can hang in that environment)

## Fixed

- Retrying `pa` release patch on an existing release branch no longer re-bumps the version and aborts mid-flow

## Upgrade

```bash
pa update
# or fresh install:
curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```
