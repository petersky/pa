# v1.4.0 — 1.4.0

**Release track:** release  
**Date:** 2026-09-06

## Summary

v1.4.0 hardens chat history and session continuity, improves card and notification fidelity in the UI, and adds GitHub browse/create support when admitting repositories. Operators and users who rely on long conversations, live card progress, or repo onboarding should upgrade.

## Highlights

- Preserve complete chat messages across paging and session transitions, with missing-history recovery after subscription replacement
- Add GitHub browsing and creation to the Add Repo dialog, including fresh repository admission
- Keep card header actions and detail summaries aligned with live progress and execution state
- Preserve structured notification choices and surface response delivery progress
- Render agent Tool Activity as sanitized markdown

## Added

- GitHub browsing and creation in the Add Repo dialog
- Concurrent dispatch reasons and coverage for fresh repository admission
- Response delivery progress for structured notification choices
- Sanitized markdown rendering for agent Tool Activity text

## Changed

- Preserve complete chat messages across paging and session transitions
- Allow missing-history recovery after subscription replacement
- Keep terminal composer messages explicit during session transitions
- Preserve advanced chat preference intents through UI updates

## Fixed

- Card detail summary health and execution truth
- Card header actions staying synchronized with progress refresh
- Out-of-band card action swaps verified in the HTMX contract
- Session readiness, bounded sidebar listing, and conversation teardown

## Upgrade

```bash
pa update
# or fresh install:
curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```
