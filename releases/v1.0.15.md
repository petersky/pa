# v1.0.15 — 1.0.15

**Release track:** release  
**Date:** 2026-08-16

## Summary

This release improves the Agent **New session** dialog so registered providers appear immediately, with clearer loading behavior while session options finish loading. Anyone who starts agent sessions from the web UI should pick this up.

## Highlights

- Registered agent providers (Codex, Cursor, OpenInterpreter) show as soon as you open **New session**
- Provider list no longer depends on slow live CLI probes that hid timed-out runtimes
- Loading state for model / mode / effort, with **Start session** disabled until options are ready
- Provider choice made while options are still loading is preserved

## Added

- Registered provider catalog rendered in the Agent page HTML, plus a `/api/agent/providers/catalog` fallback so the picker is populated immediately
- Loading state for model, mode, and effort while session options load

## Changed

- New session provider picker uses the registered catalog instead of waiting on live CLI status probes

## Fixed

- New session dialog often stuck on **Instance default** with no providers and no loading feedback when CLI probes timed out

## Upgrade

```bash
pa update
# or fresh install:
curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```
