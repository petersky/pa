# v1.0.20 — 1.0.20

**Release track:** release  
**Date:** 2026-08-20

## Summary

This patch release fixes a UI false alarm: when a card was already Done but an early dispatch had failed (for example a SQLite timeout at startup), PA could still show “Delivery failed.” Operators who saw that on closed-out cards should upgrade.

## Highlights

- Startup dispatch failures no longer land in completion outbox errors as turn-end delivery failures
- Done cards with orphaned failed or cancelled dispatches present as completed, not delivery/retry attention
- Card detail hides stale startup error text when the card is Done and no agent turn ended

## Fixed

- Stale dispatch startup failures (including SQLite timeouts) no longer show as delivery errors on Done cards after manual closeout

## Upgrade

```bash
pa update
# or fresh install:
curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```
