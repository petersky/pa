# v1.5.6 — 1.5.6

**Release track:** release  
**Date:** 2026-10-16

## Summary

This patch release hardens chat history and card-start reliability, recovers stalled automatic investigation, and sharply reduces the cost of runtime status and transcript work. Operators and anyone watching live agent chat or dispatch health should upgrade.

## Highlights

- Bound runtime status and dispatch polling, and shorten transcript transactions for much cheaper status reads
- Fix stale start previews so ordinary metadata updates no longer reject unchanged start attempts
- Recover stalled automatic investigation when a start fails with no session
- Fix chat history tail reconciliation so returning to latest resumes live updates correctly
- Assemble live chat previews into readable paragraphs instead of one fragment per line

## Changed

- Runtime and dispatch status paths use bounded, compact reads instead of full queue/dispatch snapshots
- Transcript storage shortens writer-held transactions and bounds GC publication locks

## Fixed

- Stale start previews rejected by background summary retries and admission races
- Automatic health triage waiting forever after a failed start with no session
- Chat widget stuck on a stale history view after scrolling back to the latest messages
- Fragmented live preview rendering during streamed agent replies

## Upgrade

pa update
