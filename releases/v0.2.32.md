# v0.2.32 — 0.2.32

**Release track:** release  
**Date:** 2026-07-31

## Summary

This release hardens fleet operations and configuration for PA operators: verified metadata backups, schema-driven config with a redesigned curses editor, fleet telemetry and onboarding, plus reliability fixes for remote sessions and Codex dispositions.

## Highlights

- Scheduled, verified, configurable metadata backups
- Schema-driven configuration management and a redesigned curses config editor
- Fleet resource telemetry, reports, and a durable onboarding workflow
- Bounded fleet remote activity streams and HTMX history snapshots with storage-failure recovery
- Fixes for remote agent session reliability and Codex disposition extraction

## Added

- Scheduled, verified, configurable metadata backups (#170)
- Schema-driven configuration management
- Fleet resource telemetry and reports
- Durable fleet onboarding workflow
- Redesigned interactive config editor with curses

## Changed

- Bound Fleet remote activity streams
- Bound HTMX history snapshots and recover from storage failures (#165)
- Retire terminal PR watches from Fleet topology
- Harden PA MCP owner-channel lifecycle

## Fixed

- Fix remote agent session reliability
- Fix Codex disposition extraction
