# v1.8.0 — 1.8.0

**Release track:** release  
**Date:** 2026-11-09

## Summary

The agent chat page is tighter and easier to read: bubbles render media and collapsible JSON, the chrome moves into the toolbar, and sessions adapt on narrow screens. This release also pins the ACP SDK to a known-good version and improves how peer endpoint denials show up in failure evidence.

## Highlights

- Tighter chat layout: detail tabs and tool rail in the toolbar, one-row composer, Threads bar hidden for a single thread
- Readable chat bubbles with collapsible JSON, inline media, Markdown copy, and retained prompt images
- Narrow screens focus the conversation; sessions open as a slide-over
- Sessions list shows open PRs; recovery-blocked sessions no longer look healthy in the header
- ACP SDK pinned to `0.10.1` for verified compatibility

## Added

- Collapsible embedded JSON and inline images, audio, and video in chat bubbles
- Copy any bubble as its original Markdown
- Prompt images retained so they reappear in history
- Sessions list shows open PRs (plus "+N more")
- Slide-over sessions panel on narrow screens

## Changed

- Detail tabs and tool rail live in the toolbar; the Threads bar hides when there is only one thread
- Composer grows in one row; Stop and Clear draft appear only when they apply
- Lighter per-theme prompt bubbles and a selection colour that contrasts with them
- Tips removed from the sessions list
- Peer endpoint denials are a distinct failure-evidence subtype

## Fixed

- A recovery-blocked session no longer looks healthy in the header
- ACP SDK pinned to `agent-client-protocol==0.10.1` (ACP 1.0 broke helpers used by `pa.acp.client`)

## Upgrade

```bash
pa update
# or fresh install:
curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```
