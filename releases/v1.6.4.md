# v1.6.4 — 1.6.4

**Release track:** release  
**Date:** 2026-11-08

## Summary

Patch release that finishes the superseded-session delivery recovery story from v1.6.3: when the linked run has already ended, notification cards stop offering a useless Retry and instead say the response can no longer be delivered.

## Highlights

- Superseded-source recovery no longer falls back to **Retry delivery** after the linked run has ended
- Cards report `linked_run_ended`, keep the recorded response, and offer only dismissal
- Live session/run state overrides the recovery action stored when the failure first happened (no migration)

## Changed

- Delivery-recovery presentation uses live linked-run state over the originally stored recovery action, so older records classify correctly when the linked run later ends

## Fixed

- When a superseded session is still fenced by a linked run that has closed, archived, or gone missing, the recovery card no longer offers Retry or transfer; it states that delivery to any session is no longer possible and keeps Dismiss without delivering
