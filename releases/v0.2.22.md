# v0.2.22 — 0.2.22

**Release track:** release  
**Date:** 2026-07-25

## Summary

This release hardens durable agent sessions and card workflows: orphan sessions close reliably, recovery is safer, and the Work UI gains drafts, a fuller new-card flow, and clearer card details. Operators and frequent Work-page users should update.

## Highlights

- Close durable orphan agent sessions in bulk and restore durable session routes
- Gate session traffic during durable recovery and bound unavailable-project recovery
- Persist agent chat drafts locally and PR watch session provenance
- Add a full new-card modal with attachments and tabbed sticky card details
- Reconcile missing card dispositions and recover merge commit evidence for merged PRs
