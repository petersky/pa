# v1.4.2 — 1.4.2

**Release track:** release  
**Date:** 2026-09-06

## Summary

v1.4.2 is a stability and startup-performance patch for operators hitting projection catch-up failures, stuck initial session loading, or heavy background reads. Upgrade if your instance struggles on boot, first chat entry, or status/runtime polling under large session and transcript histories.

## Highlights

- Fix incremental projection catch-up so merge parents no longer replay already-projected ancestry and crash startup
- Fix first chat mount so sidebar SSE selection no longer cancels the owner lookup and leaves “Locating session owner…” stuck
- Bound recovery, reconciliation, and PR bookkeeping reads that amplified background I/O
- Serve completed transcript diagnostic snapshots from status requests instead of rescanning on every poll

## Changed

- Recovery filters closed and archived sessions in SQL before hydrating records
- Reconciliation checks indexed completion evidence before loading pending-turn messages
- Merged-card bookkeeping queries are bounded, with durable exponential backoff for missing-card retries
- Runtime and maintenance status return the last completed transcript diagnostic snapshot (with `measured_at`); cold status reports not measured rather than starting scans

## Fixed

- Projection catch-up could revisit a completed operation through a merge’s other parent and fail receipt validation on startup
- Initial session entry could cancel its own owner/history requests when shared SSE transport closed, leaving owner resolution pending
- Stale stream and selection callbacks could still mutate controls after a session switch or widget teardown
