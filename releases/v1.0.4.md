# v1.0.4 — 1.0.4

**Release track:** release  
**Date:** 2026-08-13

## Summary

This release makes fleet instance targeting easier from the CLI and restores a normal pointer on the offline Sessions control. Operators using `pa agent-provider` across named fleet peers, and anyone using the top-bar Sessions link while the agent is offline or starting, should update.

## Highlights

- Accept fleet instance names (not just UUIDs) in `pa agent-provider … --instance`
- Show copy-pasteable instance UUIDs in `pa fleet list`
- Keep pointer cursor on the offline/starting Sessions control

## Added

- Fleet instance name resolution for `pa agent-provider … --instance`: exact UUID or case-insensitive name, shared with card dispatch, fail closed on ambiguous duplicates
- Instance UUIDs in `pa fleet list` beside name/URL/health

## Fixed

- Keep pointer cursor on the offline/starting top-bar Sessions control (remove leftover not-allowed cursor)

## Upgrade

```bash
pa update
# or fresh install:
curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```
