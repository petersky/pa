# v1.0.9 — 1.0.9

**Release track:** release  
**Date:** 2026-08-16

## Summary

This release fixes macOS launchd service management when PA runs over SSH or on a headless Mac (no Aqua console session). Operators who `pa start`, restart after update, or rely on `pa status`/`pa stop` on Mac minis and remote Macs should upgrade.

## Highlights

- Launchd bootstrap falls back from `gui/$UID` to `user/$UID` when the GUI domain rejects bootstrap (error 125)
- Status, stop, restart, and rebootstrap inspect both launchd domains so service control works without a console login
- Doctor and Mac mini deployment docs note the user-domain fallback

## Fixed

- Launchd bootstrap on headless Macs / SSH sessions no longer fails with error 125 (`Domain does not support specified action`); PA retries the user domain and manages the unit in whichever domain loaded it

## Upgrade

```bash
pa update
# or fresh install:
curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```
