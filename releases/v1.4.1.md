# v1.4.1 — GitHub SSH repository provenance

**Release track:** release  
**Date:** 2026-09-06

## Fixed

- PR supervision now recognizes GitHub repositories stored as SSH URIs or SCP-style remotes when registering an owner/name watch. HTTPS and case-insensitive repository names continue to work.
- Repository comparison rejects foreign hosts and malformed or ambiguous paths. Session, card, project, realm, dispatch, and unique repository ID validation remain enforced; stored repository URLs and execution bindings are preserved.

## Validation

- Regression coverage reproduces the SSH provenance rejection and verifies canonical watch registration, immutable bindings, foreign-host rejection, and ambiguous repository ID rejection.
- Transport parsing tests cover owner/name, HTTPS, SSH URI, SCP syntax, and malformed inputs.

## Upgrade

Run `pa update --yes` to install the release. For an active PA-managed session, activate it through PA's exact-session restart handoff after installation.
