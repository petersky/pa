# v0.2.34 — 0.2.34

**Release track:** release  
**Date:** 2026-08-01

## Summary

A UI fix release that restores page scrolling on agent, workshop, and fleet pages and keeps the agent composer pinned on-screen as chats grow. Anyone using the web UI with long transcripts should update.

## Highlights

- Restore page scrolling on agent, workshop, and fleet pages
- Keep the agent composer pinned on-screen for long chats
- Route PageDown/PageUp and other scroll keys to the page scroll region when the body has focus

## Fixed

- History-boundary wrappers sat outside the flex chain, so `.page-layout` collapsed and content was clipped by `.app-view` instead of scrolling
- Agent composer fell off-screen as chat history grew
- Scroll keys pressed with body focus did nothing because the document itself no longer scrolls in the app shell
