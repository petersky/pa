# v1.5.5 — Refresh target evidence before first admission

**Release track:** release

**Date:** 2026-10-15

## Summary

An accepted card dispatch now refreshes the target's execution evidence before
its first session check. A recent but incomplete startup cache no longer requires
an operator refresh and retry when current provider evidence supports the selected
settings. The accepted request, model, reasoning, native settings, and policy
constraints remain intact.

## Validation

Tool-free ACP regression coverage reproduces authority/target disagreement and
checks that the first attempt starts exactly one session with the original receipt.
Current policy still rejects prohibited selections. Recovery coverage verifies
that Full access, Workspace Write, Auto review, and read-only retain their chosen
mode and native conversation identity after reconnect.

## Upgrade

Use `pa update` through the normal release installation workflow. Managed turns
must use PA's durable restart handoff to continue in the same session.
