# v0.2.27 — 0.2.27

**Release track:** release  
**Date:** 2026-07-26

## Summary

This release tightens fleet dispatch reliability and operator UX: intent-aware workspace profiles for execution, safer completion acknowledgement, smarter fleet roster reconciliation, light/dark themes, and cleaner agent-chat SSE lifecycle handling. Operators running multi-node fleets and anyone dispatching work from cards should update.

## Highlights

- Intent-aware dispatch workspace profiles so repository vs. non-Git work materializes correctly
- Completion acknowledgement decoupled from card reconciliation to stop false version conflicts and retry storms
- Semantic fleet roster reconciliation for equivalent membership snapshots
- Light and dark appearance themes across the catalog
- Obsolete agent-session SSE streams closed on navigation and session changes

## Added

- Intent-aware dispatch workspace profiles (repository, research/artifact, operations, automatic) with plan summaries in the card dispatch UI
- Light and dark variants for OSU, Feelin' Pretty, Go Hawks, Nord, Solarized, Monokai Pro, ayu, and Tokyo Night themes

## Changed

- Fleet membership reconciliation now compares stable semantic fields and merges compatible equivalent rosters instead of treating volatile observation differences as conflicts
- Agent-turn completion is durably acknowledged before mutable card/lane reconciliation, with clearer reconciliation outcomes and bounded retry/backoff

## Fixed

- Close obsolete agent-session SSE streams on session changes, modal/SPA replacement, and page lifecycle transitions to avoid connection-pool exhaustion
- Stop indefinite completion redelivery retry storms triggered by unrelated card edits during acknowledgement
