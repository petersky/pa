# v1.0.21 — 1.0.21

**Release track:** release  
**Date:** 2026-08-20

## Summary

This patch release fixes local agent-session routing and repository checkout registration so local fleet dispatch and workspace inspection stay accurate. Operators running agent chat against the current instance, or inspecting repository working trees after workspace provisioning, should upgrade.

## Highlights

- Bypass the fleet HTTP self-proxy when an agent session is already owned by the current PA instance
- Use the authority’s local durable and projection heads when the dispatch target is the authority itself
- Stop publishing the shared `--no-checkout` object cache as the instance’s real repository checkout
- Allow the agent chat widget to render in standalone embeds without requiring full settings context

## Changed

- Local dispatch sync health now reads authenticated authority state in-process instead of round-tripping through the advertised fleet URL
- Agent chat widget can render standalone by accepting an explicit `current_instance_id` (falling back to settings when present)

## Fixed

- Local agent-session routing no longer depends on a fleet self-proxy path that can be unavailable even when the local app is healthy
- Workspace provisioning no longer registers the object cache as an operator checkout (which previously showed every tracked file as deleted and could overwrite a verified checkout)

## Upgrade

```bash
pa update
# or fresh install:
curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```
