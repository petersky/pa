# v1.1.4 — 1.1.4

**Release track:** release  
**Date:** 2026-08-29

## Summary

Reliability and scale release for fleet sync and durable agent sessions. Operators running multi-node sync or ACP chat should upgrade for safer projection catch-up, bounded prompt recovery, and restart-handoff race fixes.

## Highlights

- Scale sync history with indexed status, snapshot epochs, and O(delta) anti-entropy
- Make projection catch-up incremental while keeping durable tips ahead of lag
- Bound ACP prompt recovery and restore quiesce admission safely
- Fix durable restart handoff lifecycle races
- Normalize MiniMax M3 card-summary envelopes

## Added

- Indexed sync status catalogs, fleet-acknowledged snapshot epochs with audited GC planning, and checkpointable DAG rebuilds for large histories
- Projection convoy regression coverage

## Changed

- Projection catch-up is incremental; legacy one-arg rebuild callbacks still work while target-aware tips catch up before CAS
- ACP browser prompt submit uses a deadline plus durable `client_prompt_id` reconciliation; recent chat paints first from the session DOM cache; Codex commentary/thought routing is reversed

## Fixed

- Oversized sync inventory pages no longer abort anti-entropy; projections catch up before durable tip publish so head cannot race ahead of SQLite
- Durable restart handoff lifecycle races
- Quiesce admission restores after a failed quiesce unless a shutdown fence is active
- MiniMax M3 card-summary envelope normalization

## Upgrade

```bash
pa update
# or fresh install:
curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```
