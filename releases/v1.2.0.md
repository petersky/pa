# v1.2.0 — 1.2.0

**Release track:** release  
**Date:** 2026-08-29

## Summary

v1.2.0 refreshes PA’s web UI into a cohesive visual and interaction system across core surfaces, and hardens agent workspace recovery so sessions can start again when a remembered working directory is gone.

## Highlights

- App-wide UX refresh: typography, spacing, color, surfaces, controls, navigation, and responsive behavior
- Consistent hierarchy, states, and feedback across Goals, Projects, Work, Fleet, Sessions, Browse, Workshop, Settings, and login
- Accessibility improvements for keyboard focus, labeling, live regions, and mobile tables/tabs
- Scratch workspace rematerialization when a remembered agent cwd no longer exists
- Safer workspace recovery when dropping missing-cwd execution bindings

## Changed

- Established a cohesive visual system and refreshed major app flows for consistent hierarchy, states, and feedback
- Improved keyboard focus, accessible labeling, live regions, mobile tables and tabs, and related regression coverage

## Fixed

- Session start no longer fails with `Agent cwd does not exist` after a prior scratch path or binding cwd was deleted or moved; PA drops missing/data-dir paths and rematerializes an allowed scratch workspace
- Workspace recovery can remove missing-cwd bindings without being rejected by the execution-binding store

## Upgrade

```bash
pa update
# or fresh install:
curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```
