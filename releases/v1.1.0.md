# v1.1.0 — 1.1.0

**Release track:** release  
**Date:** 2026-08-23

## Summary

v1.1.0 hardens PA’s control plane for durable autonomy: restart-safe execution handoffs, goals as the primary UI with autonomous dispatch, curated Memory separate from audit history, and an optional cloud coordination plane—aimed at operators running long-lived fleets and agent sessions.

## Highlights

- Decoupled execution bindings with restart handoff, fencing, and retry-after-repair
- Durable goals as the canonical UI, with autonomous dispatch for active goals
- Curated Memory separated from audit history, wired into prompt context with limbic state
- Optional cloud coordination plane and autonomy rollout settings
- Exactly-once post-turn actions and supervised durable control-plane workers

## Added

- Restart handoff for execution workspace bindings, with access fencing and concurrency controls
- Optional cloud coordination plane and cloud coordination settings
- Autonomy rollout configuration; active goals can dispatch autonomously
- Curated Memory as a distinct surface from audit history
- Searchable Work facets (replacing the tag selector)
- Deep scrubs alongside isolated scheduled backup I/O
- Incremental loading for older chat history

## Changed

- Durable goals are the canonical UI
- Limbic and memory contribute to prompt context
- Navigation and card creation are responsive
- Card dispatch and agent session state are unified
- Transcript storage is bounded and separated from metadata
- Fleet reports are more scalable and accessible; Fleet topology stays clear under mobile nav
- PR supervisor is triageable at fleet scale; draft-specific triage status restored
- Dispatch progress is compaction-aware; collaboration policy resolves from the placed provider
- Queued dispatches stay out of attention; ACP diagnostics/shutdown draining and service log growth are bounded
- Completion SQLite writes stay off the event loop; control-plane workers are supervised
- Operator publication fences are honored; fleet workload profiles are normalized
- Agent chat browser memory is bounded; browser operations and outcome recovery are stabilized

## Fixed

- Retry failed restart handoffs after repair
- Restore durable default session after restart; resume ended sessions without replacing conversations
- Ended session menu actions
- PR supervisor executor rejection recovery
- Bound automatic session closure under contention
- Preserve canonical instance identity rendering
- Harden MCP and fleet HTTP/2 cancel recovery
- Harden service log rotation safety boundaries
