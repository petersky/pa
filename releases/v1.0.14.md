# v1.0.14 — 1.0.14

**Release track:** release  
**Date:** 2026-08-16

## Summary

A performance and CI maintenance release focused on keeping busy PA instances responsive under load, plus excluding flaky managed Chromium e2e tests from CI so parallel runs stay reliable.

## Highlights

- Prune closed-session cruft so busy instances stay responsive
- Bound card-detail queries to avoid expensive detail fetches
- Ignore managed Chromium e2e tests in CI (they SIGKILL under xdist, same class of issue as dump-dom)

## Changed

- Instance maintenance now prunes closed-session cruft and bounds card-detail queries for better responsiveness on busy instances
- CI ignores managed Chromium e2e tests under xdist to avoid SIGKILL failures
