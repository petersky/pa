## Summary

This patch keeps the agent chat composer visible as conversations grow. Desktop users with long agent transcripts should update so the input stays pinned at the bottom while only the message list scrolls.

## Highlights

- Agent composer stays pinned at the bottom of the agent view as chats grow
- Message history scrolls inside the chat stage instead of pushing the page
- Layout regression coverage for the flex/grid height chain (`min-height: 0` / overflow)

## Fixed

- Long agent sessions no longer scroll the composer off-screen; the transcript scrolls within the chat stage while the input stays sticky at the bottom
