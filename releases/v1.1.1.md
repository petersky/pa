# v1.1.1 — 1.1.1

**Release track:** release
**Date:** 2026-08-23

## Summary

v1.1.1 makes fleet synchronization safe for large histories with bounded sync protocol v3, while preserving reliable shutdown behavior and adding faster project and card creation flows.

## Highlights

- Transfer large sync histories in bounded inventory and object batches with protocol v3
- Observe and retire shielded future failures during cancellation and shutdown
- Open project, repository, and project-scoped card creation in focused modal flows

## Changed

- Sync peers negotiate protocol v3 and exchange only missing history in bounded batches
- Sync preparation diagnostics expose batch progress, residual work, retries, and compatibility failures
- Project and repository creation now opens in modals
- Project pages provide a direct project-scoped card creation action

## Fixed

- Prevent large histories from requiring an unbounded full-history sync bundle
- Preserve idempotent recovery when a bounded transfer is interrupted after a durable batch
- Observe background preparation failures after waiter cancellation so shutdown does not leave an unhandled future
- Report legacy peers that cannot safely accept a large bundle as protocol-incompatible
