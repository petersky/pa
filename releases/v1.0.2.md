# v1.0.2 — 1.0.2

**Release track:** release  
**Date:** 2026-08-07

## Summary

This release hardens terminal repair and effect/watch reliability under concurrency, and fixes Home attention queue accuracy. Operators and anyone hitting abandoned dispatch, saturated Home, or OpenInterpreter session issues should update.

## Highlights

- Atomic, fenced terminal repair that safely recovers abandoned dispatch rows and closes lifecycle races
- Recoverable, idempotent mutation outcomes and effect identity across lease takeover and auth renewal
- Evidence-based Home attention queue with complete totals, pagination, and contextual actions
- Safer PR watch renewal and fail-closed behavior for legacy watch protocols
- OpenInterpreter session-start fix with model-provider selection

## Added

- Model-provider selection for OpenInterpreter sessions
- Target reservations and authenticated hops for terminal repair
- Target-local proof requirement for terminal repair

## Changed

- Terminal repair is atomic and fenced against retry/stale follow-up races
- Mutation outcomes are recoverably idempotent
- Home attention queue is evidence-based, with bounded projections and complete totals/pagination
- PR effect prompt admission is idempotent; PR watch renewal traffic is safely bounded
- Prepared effects recover after lease takeover; effect identity is preserved across authorization renewal
- Legacy PR watch protocols fail closed

## Fixed

- Abandoned terminal dispatch row repair races and stale follow-ups
- OpenInterpreter session start
- Remote join executable detection
- Queue completion from fresh dispatch state
- Actionable watches under home saturation
- Contextual attention actions and Home retry refresh

## Upgrade

pa update

curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
