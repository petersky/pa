# v0.2.25 — 0.2.25

**Release track:** release  
**Date:** 2026-07-26

## Summary

This release deepens multi-instance fleet workflows: smarter card dispatch placement, durable remote progress, clearer instance identity in the UI, and safer reconnect/restart behavior for operators running PA across a fleet.

## Highlights

- Fleet-aware card dispatch placement when sending work across instances
- Durable remote dispatch progress visible in the UI and API
- Fleet instance names shown consistently across the product
- Canonical fleet membership with inventory repair
- Safer fleet restart teardown and more responsive reconnect during agent recovery

## Added

- Fleet-aware card dispatch placement for choosing where work runs in a fleet
- Durable remote dispatch progress tracking and UI/API exposure
- Fleet instance names surfaced throughout the UI

## Changed

- Fleet membership is canonicalized so peer inventories stay consistent
- Reconnect stays responsive while agents recover at startup

## Fixed

- Fleet restart dispatch is teardown-safe so restarts do not leave dispatch in a bad state
- Fleet inventories are repaired when membership drifts

## Upgrade

```bash
pa update

curl -fsSL https://raw.githubusercontent.com/petersky/pa/main/scripts/install-remote.sh | bash
```
